# Cài dependencies thông thường (KHÔNG bao gồm PyTorch):

# ----------------------------------------------------------
# ⚠️  CÀI PyTorch RIÊNG — Chọn đúng lệnh theo Chip/GPU máy
# ----------------------------------------------------------
# [KIỂM TRA GPU TRƯỚC] — chạy script này để biết chip nào đang dùng:
python scripts/check_gpu.py

# Sau khi xác định GPU, chạy đúng 1 trong các lệnh bên dưới:

# → NVIDIA GPU (RTX/GTX, CUDA 12.8) — Windows / Linux:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128

# → AMD GPU — Windows (CPU-only, vì DirectML không còn hỗ trợ pip):
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# → AMD GPU — Linux (ROCm 6.1):
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/rocm6.1

# → Apple Silicon M1/M2/M3/M4 (MPS tích hợp sẵn):
pip install torch torchvision torchaudio

# → Không có GPU / môi trường CI:
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cpu

# [XÁC NHẬN] — chạy lại để kiểm tra device được chọn tự động:
python scripts/check_gpu.py
