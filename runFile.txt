#
# ── HƯỚNG DẪN BATCH SIZE THEO TỪNG CHIP / GPU ──────────────────────────────
# Script hỗ trợ 2 cờ CLI: --gpu (ép dùng GPU) và --batch N (tùy chỉnh batch)
# Nếu không truyền gì: CPU đa luồng (ổn định nhất, ~100 chunks/s)
#
# ┌─────────────────────────────┬────────────┬──────────┬────────────────────────────────────────────┐
# │ Chip / GPU                  │ Lệnh khởi  │  batch   │ Ghi chú                                    │
# ├─────────────────────────────┼────────────┼──────────┼────────────────────────────────────────────┤
# │ AMD RX 580 8GB (DirectML)   │ --gpu      │  64      │ Mặc định khi --gpu, VRAM ~4GB.             │
# │                             │ --gpu      │  32      │ An toàn hơn nếu OOM: --batch 32            │
# ├─────────────────────────────┼────────────┼──────────┼────────────────────────────────────────────┤
# │ NVIDIA RTX 3050 4GB (CUDA)  │ (tự động)  │  64      │ CUDA auto, VRAM ~3.5GB. Nếu OOM: --batch 32│
# │                             │            │  32      │ python 03_build_qdrant.py --batch 32       │
# ├─────────────────────────────┼────────────┼──────────┼────────────────────────────────────────────┤
# │ Apple Silicon M4 (MPS)      │ (tự động)  │  128     │ MPS dùng RAM hệ thống, chia sẻ với CPU.   │
# │                             │            │         │ M4 Base 16GB RAM → --batch 128 an toàn.    │
# │                             │            │         │ M4 Pro/Max 24–48GB → --batch 256 tối ưu.   │
# ├─────────────────────────────┼────────────┼──────────┼────────────────────────────────────────────┤
# │ CPU only / không có GPU     │ --cpu      │  128     │ Đa luồng (OpenMP), ổn định 100%.           │
# └─────────────────────────────┴────────────┴──────────┴────────────────────────────────────────────┘
#
# Ví dụ cụ thể:
#   AMD RX 580 (DirectML), batch 64:
python scripts/offline_rag/03_build_qdrant.py --gpu
#   AMD RX 580 (DirectML), batch tùy chỉnh 32 nếu bị OOM:
# python scripts/offline_rag/03_build_qdrant.py --gpu --batch 32
#
#   NVIDIA RTX 3050 4GB (CUDA tự nhận), batch mặc định:
# python scripts/offline_rag/03_build_qdrant.py
#   NVIDIA RTX 3050 4GB, giảm batch nếu OOM:
# python scripts/offline_rag/03_build_qdrant.py --batch 32
#
#   Apple Silicon M4 (MPS tự nhận), tăng batch:
# python scripts/offline_rag/03_build_qdrant.py --batch 128
#   Apple M4 Pro/Max RAM lớn:
# python scripts/offline_rag/03_build_qdrant.py --batch 256
#
#   CPU thuần (chậm nhưng ổn định 100%, không cần GPU):
# python scripts/offline_rag/03_build_qdrant.py --cpu
#
# ─────────────────────────────────────────────────────────────────────────────
# Script có tính năng RESUME: Nếu bị ngắt giữa chừng, chạy lại cùng lệnh
# → Tự động bỏ qua các chunks đã upsert, tiếp tục từ điểm dừng.
